# Security policy

## Reporting a vulnerability or abuse concern

Please open a GitHub issue without including sensitive target data, credentials,
payloads, or command-and-control details. If private reporting is enabled for
this repository, prefer a private vulnerability report.

Reports should include the affected version or commit, impact, and a minimal
reproduction that uses harmless test artifacts.

## Scope

This repository contains only a generator for a persistence artifact. Do not
submit executable implants, live infrastructure details, or data obtained from
third-party systems.
